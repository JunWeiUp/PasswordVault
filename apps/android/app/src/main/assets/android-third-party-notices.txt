Android client dependencies

- AndroidX: Activity, Compose (UI, Material 3, Material Icons), Lifecycle, Fragment, Biometric, Credentials, CameraX, Concurrent (Google / The Android Open Source Project): Apache License 2.0
- OkHttp (Square): Apache License 2.0
- ZXing core (ZXing authors): Apache License 2.0
- Markwon (Dimitry Ivanov): Apache License 2.0
- Java Native Access (JNA): Apache License 2.0 or LGPL 2.1 (used under Apache License 2.0)
- Android desugared JDK libraries (Google): GPL 2.0 with the Classpath Exception
- common-relay protocol (implemented in vault-core, MIT): see crates/vault-core/tests/fixtures/relay-protocol/LICENSE-common-relay
