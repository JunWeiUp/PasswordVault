## Final prompt

Use case: illustration-story. Asset type: wide editorial hero illustration for the README of PasswordVault, a local-first open source password manager. Create a refined, tactile paper-and-ceramic illustration on a very pale warm gray background. A small sculptural deep-blue vault with a simple keyhole stands at the center; neatly arranged ivory credential cards, a six-dot authenticator token, and a folded private note sit nearby. A fine blue dotted path quietly connects the objects. Calm precise composition, generous negative space, subtle soft shadows, front three-quarter view, sophisticated utility-product art direction. Restrained ink blue, cobalt #315CE7, ivory and one pale amber detail. No cloud, no people, no real passwords, no text, no lettering, no logos, no watermark, no interface screenshot. Landscape 16:9. This is a conceptual illustration, not a claim of security certification.
