# Code of Conduct

Be respectful, specific, and patient. Welcome people of all backgrounds and experience levels. Critique the work rather than the person, credit others, and protect private information.

Harassment, threats, discriminatory language, impersonation, doxxing, and unwanted sexual attention are not acceptable. Do not post other people's credentials or private data.

Maintainers may edit or remove harmful content, pause a discussion, restrict participation, or ban repeated offenders. Decisions should be proportionate and explained when doing so does not expose private information.

For misconduct reports, use GitHub's private abuse reporting tools or a private contact listed on a maintainer's GitHub profile. Do not create a public issue containing private details.
